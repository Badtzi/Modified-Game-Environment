================================================================================
                    TREK 4.0 — SCRIPT INTERCONNECTION MAP
================================================================================

LEGEND:
  ───────>  RemoteEvent (client-to-server)
  <───────  RemoteEvent (server-to-client)
  <=======  RemoteEvent (server-to-all-clients)
  - - - ->  BindableEvent / BindableFire
  ........> Attribute channel (SetAttribute → GetAttribute)
  ~~~~~~~~> Module require()
  [shared.*] Global shared table read/write


================================================================================
 LAYER 1: BOOTSTRAP (runs first, populates shared.S)
================================================================================

  SERVER:  TREKServerGeneral.luau
           Writes: shared.S (all TREK_SERVICES children mapped by name)
                   shared.S.globalConfig
                   shared.S.trekFuncs  (LeaderBoardModule)
                   shared.S.trekGibs   (TREKGibsModule)
                   shared.S.trekServerFuncs (TREKServerFunctions)
           Requires: LeaderBoardModule, TREKExplosionModule, TREKServerFunctions

  CLIENT:  LocalHandler.luau (StarterPlayerScripts)
           Writes: shared.S (client-side mirror of TREK_SERVICES)
                   shared.S.globalConfig
                   shared.S.trekFuncs  (LeaderBoardModule)
           Listens: Feed, SystemMessage, LocalSound (from server)

 COMMUNICATION CHANNEL SUMMARY
================================================================================

  REMOTE EVENTS (Client → Server):
    Damage, GFX, AmmoRemote, Reload, Explosion, ProjectileRemote,
    RayRemote, VoicePlayRequest, BipodDeploy, BipodUndeploy, BipodAim,
    MeleeDamage, TakedownRequest, ExplosiveThrow, ExplosiveDrop,
    ExplosivePinPull, ExplosiveAmmo, ReplicateAim

  REMOTE EVENTS (Server → Client/All):
    GFX, Explosion, TakedownSync, TakedownCancel, VoicePlayBroadcast,
    ExplosiveGFX, ExplosiveConcuss, ExplosiveAmmo, DynamicWeaponDestroyed,
    DestructionFX, ProjectileRemote, RayRemote, SystemMessage, Feed,
    LocalSound, Reload

  BINDABLE EVENTS (Local):
    ProjectileBind, RayBind        (Gun → local render scripts)
    ToggleShiftLock, EditConfig    (BipodController → SmoothShiftLock)

  SHARED GLOBALS:
    shared.S              Written by bootstrap, read by everything
    shared.S.globalConfig Written by bootstrap, read by Gun/effects
    shared.S.trekFuncs    LeaderBoardModule (kill feed, scoring)
    shared.S.trekGibs     TREKGibsModule
    shared.S.trekServerFuncs  TREKServerFunctions (config lookup)
    shared.VoicePlay      Written by TREKVoiceServer, called by 5 scripts
    shared.BipodForceExit Written by TREKServerBipod, callable anywhere
    shared.Cursors        Read by Gun, Melee, Explosive (cursor icons)

  ATTRIBUTE REGISTRY (character unless noted):
    IsCrouching        Set: ControlsModule    Read: Animate, DirWalk
    IsProne            Set: ControlsModule/Roll  Read: Animate, AimRep, Roll, DirWalk
    IsSprinting        Set: ControlsModule    Read: CameraBobbing, Roll
    BipodActive        Set: TREKServerBipod   Read: Gun, AimRep, RHM, BipodCtrl, DirWalk
    BipodDeploying     Set: TREKServerBipod   Read: Gun, AimRep, RHM, BipodCtrl, DirWalk
    TakedownActive     Set: Melee/TBurning/DynWpn  Read: AimRep, BipodCtrl, DirWalk
    InTakedown         Set: TREKServerMelee   Read: TREKServerBipod, BipodCtrl, DirWalk
    PatrolActive       Set: Gun.luau          Read: AimReplication
    InspectActive      Set: Gun.luau          Read: AimReplication
    YawLockActive      Set: Gun/Melee/Explosive  Read: AimReplication
    AimLockDisabled    Set: Explosive          Read: AimReplication
    AimPitch           Set: TREKServerGeneral  Read: AimReplication
    ProneActive        Set: ProneController    Read: (replication)
    ProneYawOffset     Set: ProneController    Read: (replication)
    ProneEntryOffset   Set: Roll.luau          Read: ProneController
    TBurningActive     Set: TBurning           Read: Gun, TREKDamageModule
    MovementAnimsLocked Set: TBurning/BipodCtrl  Read: BipodController
    PostDestructionMode Set: DynWeapons_Client  Read: Gun.luau (anim remap)
    DynamicDisabled    Set: TREKDynamicWeapons  Read: Gun.luau
    CanDeployBipod     Set: level designer     Read: TREKServerBipod, BipodCtrl
                       (on workspace parts)

  SCRIPTS EXTERNALLY DISABLED (Enabled=false):
    "Directional Walking Script" — by BipodCtrl, Melee, GFXRender, DynWpnClient

================================================================================
 DEPENDENCY CHAINS (follow the arrows)
================================================================================

  DAMAGE PIPELINE:
    Gun/Melee/Explosive (client)
      ──[Damage/MeleeDamage]──> TREKServerDamage / TREKServerMelee (server)
        ~~requires~~> TREKDamageModule
          ~~requires~~> LeaderBoardModule ──[Feed/LocalSound]──> client
        ──[shared.VoicePlay]──> TREKVoiceServer ──[VoicePlayBroadcast]──> TREKVoiceClient

  EXPLOSION PIPELINE:
    Explosive (client)
      ──[ExplosiveThrow]──> TREKServerExplosive
        ~~requires~~> TREKExplosionModule
          ──[Explosion]──> all clients (GFXRender handles VFX)

  BIPOD PIPELINE:
    Gun.luau ~~requires~~> TREKBipodController
      ──[BipodDeploy/Undeploy]──> TREKServerBipod
        ......BipodActive/BipodDeploying......> AimRep, RHM, DirWalk, Gun

  PROJECTILE/RAY RENDER PIPELINE:
    Gun.luau ──[ProjectileRemote]──> TREKProjectileRenderServer <=====> ProjectileRender
    Gun.luau ──[RayRemote]──> TREKRayRenderServer <=====> RayRenderer
    Gun.luau - -[ProjectileBind]- -> ProjectileRender (local fast path)
    Gun.luau - -[RayBind]- -> RayRenderer (local fast path)

  MOVEMENT STATE PIPELINE:
    MovementHandler (key input)
      ──> ControlsModule (state machine)
        ......IsCrouching......> Animate, Directional Walking Script
        ......IsProne......> Animate, AimReplication, Roll
        ......IsSprinting......> CameraBobbing, Roll

  VOICE PIPELINE:
    Client triggers: Gun/Melee/Explosive ──[VoicePlayRequest]──> TREKVoiceServer
    Server triggers: TREKServerDamage, TBurning, TREKGibsModule, TREKDynamicWeapons
      ──[shared.VoicePlay()]──> TREKVoiceServer
        ──[VoicePlayBroadcast]──> TREKVoiceClient (3D sound + subtitle)

  DYNAMIC WEAPONS PIPELINE:
    TREKDynamicWeapons (server, monitors tool health)
      ──[DynamicWeaponDestroyed]──> TREKDynamicWeapons_Client
        ......PostDestructionMode......> Gun.luau (remap animations)
      ──[DestructionFX]──> all clients (visual effects)
